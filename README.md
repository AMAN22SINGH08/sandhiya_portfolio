## 🛠️ Quick Start

```bash
# 1. Navigate to project directory
cd sanidhya-portfolio

# 2. Start development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```

---

## 📷 Adding Your Profile Photo

1. Copy your portrait photo file into the `public/` directory and name it `sanidhya-sharma.jpg` (or update `profileImage` in `src/portfolioData.js`).
2. The website will automatically render your photograph within the luminous orbital frame! If no image file is detected, it automatically falls back to an astronaut/developer celestial crest.

---

## 📬 Customizing Contact Details

Open `src/portfolioData.js` to update:
- `email`: Your personal email address
- `linkedin`: Your LinkedIn profile URL
- `github`: Your GitHub profile URL
